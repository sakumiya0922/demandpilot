# DemandPilot — 採用担当者向け概要

## 30秒で分かるプロジェクト

**目的:** 業務で経験が限られていたPostgreSQL、Docker Compose、データ処理基盤と、機械学習モデルからWebアプリまでの連携を一通り実装すること。

**題材:** 公開小売取引データを用いた翌7日間の需要予測と、仮定の現在庫・安全在庫に基づく簡易補充数の試算。

**開発範囲:** データ品質確認 → 日次集計 → PostgreSQL保存 → 時点整合性を保つ特徴量 → LightGBM/ベースライン比較 → 保存モデルの独立推論 → Streamlit画面 → Docker Compose → pytest。

## 実装で意識したこと

| 観点 | 実装・検証 |
| --- | --- |
| データ品質 | キャンセル・不正値等の除外理由を記録し、対象期間と商品選定の時点を固定 |
| DB | PostgreSQLに商品・取引・日次販売を保存し、再処理時の整合性を検証 |
| モデル | 学習・検証・テストを時系列で分離。LightGBMと直近7日ベースラインを比較 |
| 推論 | 学習と分離したコマンドで保存モデルを読み込み、翌7日間の販売合計を推論 |
| アプリ | 商品の販売履歴・予測・精度・補充計算を同一画面で確認 |
| 品質確認 | 前処理、DB、モデル、UIを含む53件の自動テストを整備 |

## テスト結果と判断

| 翌7日合計のテスト指標 | LightGBM | 直近7日ベースライン |
| --- | ---: | ---: |
| MAE（個） | 274.01 | **206.67** |
| WAPE | 57.41% | **43.30%** |

**モデルはベースラインを下回った。** 精度改善や業務導入を成果として主張せず、比較検証が実装できていること、および今後のモデル改善課題を示す。
