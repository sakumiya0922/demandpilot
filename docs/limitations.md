# データ・モデル・補充計算の制約

## データの範囲と品質

UCI Online Retailの2010-12-01〜2011-12-09の取引を使用。卸売を含むオンライン小売のデータで、日本の一般的な店舗販売を代表するものではない。集計は全ての国を含み、地域差はモデル化していない。

最終日の12月9日は途中までの取引のため除外し、観測終了日は12月8日に固定。返品・キャンセル・負の数量・非正の単価を除くため、返品差し引き後の純販売ではない。予測するのは観測された販売数量で、欠品による販売機会損失を含む潜在需要ではない。

販売なしを0補完するが、欠品・休業・データ未収録を区別できない。完全一致行5,268件は実取引としての意味を確認できないため保持。大口取引も保持しており、数量の最大値74,215が残る。統計値と件数は[品質確認結果](data_preparation.md)に記録。

商品コードは数字5桁＋英字0〜2桁で判定し、特殊な商品コードを除外し得る。選定した30商品は学習期間に十分な販売履歴がある商品に限るため、新商品や販売が少ない商品には適用していない。

## モデルと評価

予測は翌7日間の合計であり、日別予測ではない。実績が完全にない2011-12-09〜15日は推論だけを行い、精度を測定しない。予測区間・信頼区間は推定していない。

学習の毎日のラベルは重複する。検証は8基準日、テストは5基準日のため、テスト150行は150個の独立した週を意味しない。同一週の商品の誤差は相関し得る。検証・テストの端の未評価日も残る。複数年・複数期間のバックテストや他データでの外部検証は未実施。

検証MAEでモデルを選び、テストを調整に使用していない。テストではLightGBMのMAE274.01・WAPE57.41%が、ベースライン206.67・43.30%を下回る。特に商品22197の販売水準変化と誤差が大きい。学習・検証との差もあり、過学習と需要水準変化への追随不足を否定できない。詳細は[商品別結果と考察](evaluation.md)に記録。

全体WAPEは商品別指標の単純平均ではない。大きな実績数量を持つ商品の誤差の寄与が大きい。実績合計0ではWAPEは算出不可。小さい誤差が望ましいが、発注コストや欠品コストの最適性を直接評価する指標ではない。

評価用モデルは学習期間のみで学習したモデル。最終モデルは固定したパラメータで以前の検証・テスト期間も含めて再学習する。この最終モデルの訓練結果を独立テスト精度として表示しない。

## 補充シミュレーション

```text
推奨補充数 = max(0, ceil(7日合計予測 + 安全在庫 − 現在庫))
```

現在庫・安全在庫はユーザーの仮定値。安全在庫を統計的に推定していない。発注リードタイム、発注残、発注ロット、最低発注数量、賞味期限、保管容量、欠品・保管コストは考慮しない。予測数量は未丸めで計算し、最終補充数の端数を切り上げる。

これは7日需要を即時補充できるという単純な計算を試す機能で、在庫最適化・自動発注・実務への導入実績ではない。商品を切り替えても入力した仮定在庫は保持されるため、選択商品に合う値を入力する必要がある。

## 再現性と運用の範囲

Python・主要ライブラリ・解決済み依存バージョンを固定し、seedと決定的学習を設定している。実機検証はMac Apple Silicon / Linux aarch64。amd64・Windowsでは動作・数値の完全一致は未検証。ベースイメージのタグやOSパッケージは将来更新され得るため、Docker環境全体の永久的なビット単位再現を保証しない。

元Excelのハッシュ、日次データのハッシュ、学習条件を保存し、テーブル内容と保存モデルの予測を検証できる。`prepare-data`は専用テーブルを置き換え、`train`は成果物を更新するため、既存状態を保持する検証では[独立環境](reproducibility.md)を使用する。

ローカルMVPであり、認証・権限管理、監視、定期取得・定期再学習、モデルレジストリ、クラウドデプロイ、実在庫システム連携は未実装。学習成果物を準備しないと予測画面は使用できない。

## 残課題

- GitHubへの公開とremote設定。実際の認証情報・元データ・生成モデルは公開対象外。
- 他の実行環境での再現検証。依存更新時のStreamlit／Altair非推奨API警告の確認。
- 運用化する場合の実在庫・リードタイム等のデータ連携と業務コスト評価。
- 精度を改めて検証する場合は、既知のテスト結果を使った改善を独立評価と呼ばず、別の未使用期間やデータで評価する必要がある。

今回の完成作業では新機能・追加チューニング・GCPへのデプロイは行わない。
